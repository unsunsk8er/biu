## 安装前必读

1. 这是 **release 构建**（不可调试），使用临时验证密钥签名，不能作为正式分发包。
2. 品牌重命名后 `applicationId` 已变为 `com.unsunsk8er.biu`，与旧版安卓包不同，**不能覆盖安装**，两个包可以并存。
3. 如需清理旧版图标/数据，可在系统桌面长按旧应用卸载；卸载会清空旧包的歌单、登录态与缓存。
4. 安装新包：
   ```bash
   adb install biu-2.0.0-android-verify.apk
   ```
   或把 APK 传到手机，允许“安装未知来源应用”后点击安装。
5. 新包首次启动需要重新扫码登录（Android 包名变更，旧包数据不迁移）。
6. 本包只用于验收，不要分发；正式发布必须用真实 release keystore 重新构建。

## 验收项（按顺序）

### 1. 冷启动

- [x] 桌面图标正常，点击后出现启动页，无闪退/白屏。
- [x] 首页/推荐能加载，底部导航（推荐、搜索、喜欢、歌单、设置）可切换。
- [x] 系统返回键行为正常；从播放页返回不丢当前页。

### 2. B 站扫码登录

- [x] 设置 → 登录，二维码能正常显示（不是空白/裂图）。
- [x] 用 B 站 App 扫码并确认后，App 显示已登录、头像/昵称正确。
- [x] 杀掉进程重开，登录态仍保留。
- [x] 退出登录后，再扫码可以重新登录。

### 3. 搜索与播放

- [x] 搜索“周杰伦”，结果列表有封面、标题、UP 主、时长。
- [x] 点击歌曲能开始播放，进度条走动，封面/标题正确。
- [x] 暂停/继续、上一首/下一首、拖动进度、音量/静音正常。
- [x] 多 P 视频能选择分 P，切换后标题/进度正确。
- [x] 播放中切到后台，音频继续；回到前台状态一致。

### 4. 通知栏与媒体控制

- [x] 播放时出现媒体通知，封面/标题/歌手正确。
- [x] 通知上的播放/暂停、上一首/下一首能控制 App。
- [x] 锁屏界面能看到媒体卡片并能控制。
- [x] 暂停后通知仍可恢复播放；退出播放后通知消失。
- [ ] （可选，未单独确认）来电/微信语音时自动暂停，结束后不自动恢复。

### 5. 后台存活

- [x] 播放中切到其他 App 10 分钟，音频不中断。
- [x] 长时间后台后回到 App，界面不白屏、进度不跳变。
- [x] 锁屏 10 分钟后解锁，通知与播放状态仍在。
